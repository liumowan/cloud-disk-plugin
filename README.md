# 网盘文件批量重命名

> 一个 Tampermonkey 油猴脚本，给**百度网盘 / 阿里云盘 / 夸克网盘 / PikPak** 的文件列表加上「批量重命名」能力。
> 主打场景：**批量删掉文件名里的广告词、网址、水印，并支持整个网盘一次性处理。**

## 它能干什么

| 能力 | 说明 |
|---|---|
| 🔤 **正则批量替换** | 默认模式。用正则删掉 `【www.xxx.com】`、`[广告词]`、`-XXX影视` 之类垃圾片段 |
| 📺 **系列模式** | 按 `标题.S01E01` 自动编号，做剧集整理 |
| 📁 **文件夹也支持改名** | 文件夹不会被误加扩展名或 `.E01` 集数 |
| 🌐 **全盘加载** | 不再局限于"当前目录那几百个文件"，可递归遍历整个网盘 |
| 🔍 **全盘搜索** | 输入关键词，跨所有目录找出匹配文件，一次批量处理 |
| 📊 **改名前后对照** | 左右两列高亮差异，改什么一目了然 |
| ☑️ **区间选择** | 按住 `Shift` 点某行 → 从上次点击行到当前行之间全部选中/取消 |
| 🖱️ **滑动选择** | 在列表上按住左键拖动，划过哪行选哪行（类似 Excel） |
| 🔁 **连续作业** | 重命名后不刷新页面、不关面板、正则保留，可一批接一批 |
| 🕘 **历史记录** | 常用正则一键回填，不用每次重敲 |
| 🧹 **广告词自动检测** | 扫描文件名里高频重复的片段，自动识别疑似广告词 |
| ⚠️ **冲突预检** | 空文件名、重名（按目录判定）实时提示，避免整批失败 |

## 安装

### 方式一：一键安装（推荐）

先装好浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 均可），然后点下面的链接：

```
https://raw.githubusercontent.com/afeireal/cloud-disk-plugin/main/cloud-disk-plugin-tamper-monkey.user.js
```

> 访问 `raw.githubusercontent.com` 困难时，可用 jsDelivr 镜像：
> ```
> https://cdn.jsdelivr.net/gh/afeireal/cloud-disk-plugin@main/cloud-disk-plugin-tamper-monkey.user.js
> ```

Tampermonkey 会弹出安装页，点「安装」即可。

### 方式二：手动安装

1. 下载 [`cloud-disk-plugin-tamper-monkey.user.js`](./cloud-disk-plugin-tamper-monkey.user.js)
2. 打开 Tampermonkey → **管理面板** → **+**（新建脚本）
3. 用下载到的内容**整体替换**编辑器里的模板 → `Ctrl + S` 保存

### 安装后自检

刷新网盘页面，按 `F12` 打开控制台，应该看到一行蓝色横幅：

```
[网盘批量重命名] v1.4.4 已加载
```

面板右上角也会显示 `当前版本：1.4.4`。**两者对不上，说明装的是旧脚本。**

## 使用

### 快速上手

1. 打开网盘文件列表页
2. 点击页面上的插件入口（工具栏按钮 / 侧边栏「批量重命名」）
3. 选择模式、填写规则
4. 看右列「新文件名」确认无误
5. 点 **应用**

### 场景一：批量去广告词

文件名长这样：

```
【www.guziyuan.cn】交易01.flv
【www.guziyuan.cn】交易02.flv
```

| 字段 | 填什么 |
|---|---|
| 模式 | 正则模式 |
| 查找 | `【www\.guziyuan\.cn】` |
| 替换 | 留空 |
| 转义特殊字符 | ✅ 勾上（这样 `[`、`(`、`.` 都会被当普通字符） |

结果：`交易01.flv`、`交易02.flv`

> 💡 懒得写正则？点面板上的 **广告** 按钮，让它扫一遍，自动列出高频广告片段。

### 场景二：处理整个网盘

面板默认只读取**当前目录**，所以最先看到的往往只有几百个文件。要处理整盘：

1. **把搜索框清空**
2. 点 **搜索全盘**

脚本会从根目录 `/` 递归遍历所有文件夹，把整盘文件装进列表（上限 2 万，遍历需要几分钟，期间别重复点）。

想只看某类文件？在搜索框填关键词再点，就变成跨目录搜索。

### 场景三：剧集自动编号

| 字段 | 填什么 |
|---|---|
| 模式 | 系列模式 |
| 标题 | 剧名（留空则沿用原文件名） |
| 季数 | `1` → 生成 `.S01` |
| 自动集数 | ✅ 勾上 → 追加 `.E01`、`.E02`… |

集数按列表顺序（可用左侧 `⣿` 拖动调整）。

## 常见问题

<details>
<summary><b>「应用」按钮是灰的，点不动</b></summary>

1.4.1 起已彻底修复。按钮**只在重命名进行中**才禁用；其它情况点它会直接告诉你原因（文件名为空 / 规则没产生改动 / 没勾选文件）。

如果你装的还是旧版，请升级到最新版。
</details>

<details>
<summary><b>为什么只看到 500 个文件？</b></summary>

**不是插件限制，是当前目录本来只有这么多。** 面板默认只读取当前目录。

要处理整盘 → 清空搜索框 → 点「搜索全盘」，会递归遍历所有目录。
</details>

<details>
<summary><b>明明文件名一样，为什么只有前几个被勾选？</b></summary>

1.4.2 起已修复。旧版把「新文件名相同」当成重复，**没区分目录**——不同子目录里的同名文件（比如多个 `VIDEO_TS` 文件夹里的 `VIDEO_TS.BUP`）被误判成冲突而自动取消。

现在按「目录 + 文件名」判定，只有**同一目录下**才会真正冲突。
</details>

<details>
<summary><b>每次重命名完都要重新加载页面、重新输入规则？</b></summary>

1.4.4 起已修复。旧版重命名成功后会「关闭面板 + 清空正则 + 整页刷新」，现在改成：

- 面板保持打开
- 正则、替换文本、搜索词全部保留
- 列表**原地更新**成新文件名，成功的项自动变成"无改动"，不会被重复处理

于是可以一批接一批地清，全盘列表也不会因为刷新而丢失。
</details>

<details>
<summary><b>为什么有两个勾选框：自动集数 / 转义特殊字符？</b></summary>

- **自动集数**：默认关闭。做剧集编号才勾，否则去广告时会误加 `.E01`
- **转义特殊字符**：默认开启。勾上后 `[`、`(`、`.`、`*` 等按普通字符处理（把 `[广告]` 当成完整字符串删掉），不勾才是纯正则语义
</details>

<details>
<summary><b>重命名失败了怎么办？</b></summary>

脚本使用网盘的异步任务接口，并会轮询任务结果。部分失败时会明确提示「部分重命名失败（N 个未成功）」，成功的部分会保留并显示在列表里。

如果整批都失败，通常是登录态过期，刷新页面重新登录即可。
</details>

## 开发

脚本是**打包后的构建产物**（单文件、压缩变量名）。修改时请注意：

- ❌ **不要格式化 / 反混淆**整个文件，否则 diff 会变成几千行
- ✅ 直接在原文件上做局部修改，改完务必校验语法
- ✅ 顶部 `localVersion` 与 `// @version` 必须一致

```bash
# 语法校验
npm run check

# 修改版本号（同时改 @version / localVersion / package.json）
npm run bump 1.4.5
```

提交前请确认 **没有把 `.har`、Cookie、抓包文件带进仓库**（`.gitignore` 已拦截，CI 也会检查）。
