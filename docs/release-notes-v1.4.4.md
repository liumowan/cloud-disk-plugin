本版本重点解决三件反复被反馈的痛点：**「应用」按不动**、**只有当前目录那 500 个文件**、**每次改完都要刷新页面重来**。

### 🔧 主要修复

| 问题 | 原因 | 现状 |
|---|---|---|
| 「应用」按钮永久灰白、点都点不了 | 上一次重命名卡死后 `replaceParamsDisabled` 一直为 `true`，旧版没有任何地方复位 | 按钮只在重命名进行中禁用；每次打开面板强制复位全部瞬时状态；另加 3 分钟看门狗 |
| 重命名后必须刷新页面、重新输规则 | 成功后执行「关闭面板 + 清空正则 + `location.reload()`」 | 面板不关、正则与搜索词保留、列表**原地更新**为新文件名，可连续作业 |
| 明明文件名一样，只有前几个被勾选 | 重复判定只比较新文件名，未区分目录 | 改为按「目录 + 文件名」判定，不同子目录的同名文件不再被误取消 |
| 调用了不存在的接口 `/api/filelist`（404） | 历史遗留错误 | 全部改为真实的 `/api/list` + `bdstoken` |
| 面板报 `Cannot read properties of null (reading 'length')` | 状态计算异常冒泡进 Vue 渲染流程 | 关键路径全部加异常隔离，出错不再拖垮面板 |

### ✨ 新增能力

- **全盘加载**：搜索框留空点「搜索全盘」→ 从根目录递归遍历整个网盘（不再是"当前目录那几百个"）
- **搜索翻页取全**：不再卡在第一页 500 条
- **连续作业**：一批改完直接勾下一批
- **版本自检**：控制台打印 `[网盘批量重命名] vX.Y.Z 已加载`，面板右上角显示当前版本
- **转义特殊字符**开关：`[广告词]`、`(xxx)`、`www.xxx.com` 这类内容按普通字符处理，不必手写转义

### 📦 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 点下方附件 `cloud-disk-plugin-tamper-monkey.user.js` 下载，拖进浏览器 → Tampermonkey 会弹出安装页 → 点「安装」
3. 或直接访问一键安装链接：`https://raw.githubusercontent.com/liumowan/cloud-disk-plugin/main/cloud-disk-plugin-tamper-monkey.user.js`

### ✅ 安装后自检

- 面板右上角：`当前版本：1.4.4`
- 控制台（F12）：`[网盘批量重命名] v1.4.4 已加载`

两者对不上说明装的是旧脚本，请删除后重新安装。

### ⚠️ 注意

批量改名**不可撤销**。建议先在一两个文件上验证正则，确认「新文件名」列显示正确后再全量应用。
